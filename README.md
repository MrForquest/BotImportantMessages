# BotImportantMessages

Telegram-бот для групповых чатов на Python + aiogram 3. Следит за важными сообщениями, расшифровывает аббревиатуры и отвечает на вопросы через LLM.

## Возможности

### Фильтрация важных сообщений
Бот отслеживает сообщения в чате и пересылает в отдельный канал те, что содержат заданные ключевые слова или вложенные документы. Ключевые слова задаются через переменную окружения `IN_TEXT`.

### Расшифровка аббревиатур
- `/abbr {слово}` - расшифровать сокращение или аббревиатуру
- `/blt {аббревиатура}` - расшифровка с нецензурным акцентом
- Автоматически срабатывает с вероятностью 6% на сообщения в целевом чате - находит короткие слова и предлагает написать их полностью

Используется морфологический анализатор [pymorphy2](https://pymorphy2.readthedocs.io/) для работы с русским языком.

### AI-ассистент (Маркиса)
Бот имеет персонажа «Механическая Маркиса» - AI-собеседника на базе OpenAI-совместимого API. Учитывает историю чата (последние 30 сообщений).

| Команда | Описание | Доступ |
|---|---|---|
| `/story {текст}` | Сгенерировать ответ на основе истории чата | Все |
| `/get_list_prompts` | Список доступных промптов | Все |
| `/full_clean` | Очистить всю историю сообщений | Только владелец |
| `/set_system_prompt {текст}` | Установить системный промпт | Только владелец |
| `/set_file_prompt {имя файла}` | Загрузить промпт из файла | Только владелец |
| `/get_current_prompt` | Показать текущий системный промпт | Только владелец |

## Установка и запуск

### Через Docker (рекомендуется)

```bash
docker build -t bot-important-messages .
docker run --env-file .env bot-important-messages
```

### Локально

```bash
pip install -r requirements.txt
python bot/main.py
```

## Конфигурация

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=            # токен Telegram-бота
REPORT_CHANNEL_ID=    # ID канала для пересылки важных сообщений
IN_TEXT=              # ключевые слова через ", " (напр. "важно, срочно, документ")
SHIK_ID=              # ID целевого чата для аббревиатур
TEST_ID=              # ID тестового чата
BOT_ADMIN_ID=         # Telegram ID владельца бота
MODEL_NAME=           # название LLM-модели
MODEL_API_BASE_URL=   # базовый URL OpenAI-совместимого API
GPT_TOKEN=            # API-ключ
MODEL_SYSTEM_ROLE_NAME= # роль системного сообщения (обычно "system")
```

## Структура проекта

```
bot/
├── main.py                         # точка входа, инициализация бота
├── config.py                       # загрузка переменных окружения
├── middlewares.py                  # HistoryMiddleware, MultiHandlerMiddleware
├── db/
│   └── curse_words.db              # база для расшифровки аббревиатур
└── services/
    ├── import_message_sorter/      # фильтрация и пересылка важных сообщений
    ├── abbreviation_decipherer/    # расшифровка аббревиатур
    ├── cat_story/                  # AI-ассистент, управление промптами
    └── utils/                      # реестр команд, вспомогательные хендлеры
```

## Технологии

- [aiogram 3](https://docs.aiogram.dev/) - асинхронный фреймворк для Telegram Bot API
- [pymorphy2](https://pymorphy2.readthedocs.io/) - морфологический анализатор русского языка
- [openai](https://github.com/openai/openai-python) - клиент для OpenAI-совместимых API
- Docker - контейнеризация
